Part A — HTML/CSS (25 pts)

1. Create PartA.html with this structure in the correct order:
- header: site title (your name is fine)
- nav: 3 links (they can be # placeholders)
- main: at least two sections (you choose the content)
- footer: your name + year
2. Create a style.css file and link it in head

3. Include at least 5 CSS rules, such as:
- body font stack, base colors
- spacing (margin/padding) on sections
- simple link styling (normal + hover if you like)

4. Keep layout simple; Flexbox is optional here.

Part B — JavaScript Program (50 pts)

In PartB.js (linked at the end of body):

1. User Input (prompt)
- Ask for at least two values using prompt()
- If you need numbers, wrap with Number(prompt(...)).

2. Conditionals
- Implement at least two separate if/else decisions that use the user's input.
- Include one nested if (an if inside another if).
- Use strict equality (===, !==) where appropriate, and comparisons (>, >=, etc.) when numeric.

3. Loop
- Include at least one loop (for or while) that uses either:
- a count based on user input, or
- logic inside the loop (e.g., a simple FizzBuzz, or printing a pattern)

4. Output
- Print all program results to the Console with console.log().
- You may theme your logic however you like
(shopping, sports, movies, grades, etc.). Keep it clear and commented.

- > vs >=
